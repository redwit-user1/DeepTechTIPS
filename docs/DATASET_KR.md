# 국내 연구데이터 특화 데이터셋

기존 평가는 **영어·바이오(SciFact)** 한정이었다. 과제 KPI 는 한국어 R&D 문서가 대상이므로
한국어·국내 연구 맥락의 데이터가 필요하다. 그 격차를 메우기 위한 작업.

## 확보 현황

| 출처 | 상태 | 내용 |
|---|---|---|
| **ClinicalTrials.gov (국내 기관)** | **확보** (MCP) | 국내 연구기관 연구과제 **22건 실데이터** |
| bioRxiv/medRxiv | 확보 (MCP) | 국내 기관 프리프린트 |
| arXiv | 차단 | egress 정책 — `ArxivAdapter` 준비 완료(파서는 오프라인 테스트됨) |
| ScienceON / NTIS | 차단 | egress 정책 — 어댑터 준비, 발급키 필요 |
| KCI / AI Hub | 차단 | egress 정책 |

확보 기관: 서울대병원·분당서울대·보라매·서울아산·삼성서울·세브란스·강남세브란스·
연세대·고려대·충남대(병원)·지엔티파마·말기신부전임상연구센터

> 기관 필터(`KR_INSTITUTIONS`)로 해외 기관을 배제한다 — ClinicalTrials 의 sponsor 검색은
> 퍼지 매칭이라 University of Houston 등이 섞여 들어온다.

## 데이터 성격 (정직한 기술)

한국어 문장은 **실제 국내 연구과제 메타데이터를 R&D 문체로 렌더링**한 것이다.
- **사실은 실데이터**: 기관명·과제번호·등록례수·개시연도 모두 실제 값
- **문장 형태는 템플릿**: 자연 한국어 코퍼스를 수집한 것이 **아니다**

따라서 한국어 토크나이제이션·수치/귀속 검증 평가에는 유효하지만,
**자연 한국어 문체 다양성 평가로는 부족하다.** 후자는 ScienceON/KCI 수집이 필요하다.

## ALCOA+ 속성별 변조 설계

환각 3유형이 아니라 **ALCOA+ 속성 위반**에 직접 대응시켰다.
국내 R&D 감사(연구노트 점검·GLP)에서 실제로 지적되는 항목이기 때문이다.

| 변조 | 위반 속성 | 현실 시나리오 |
|---|---|---|
| `sponsor_swap` | Attributable (귀속가능) | 타 기관 성과를 자기 성과로 귀속 |
| `enrollment_tamper` | Accurate (정확) | 등록례수 부풀리기 |
| `date_shift` | Contemporaneous (동시적) | 수행시점 소급 기재 |
| `id_fabrication` | Original (원본) | 존재하지 않는 과제번호 |
| `no_source` | Attributable | 출처 없는 주장 |

## 이 작업이 드러낸 실제 결함

한국어 데이터를 넣자마자 **국내 시장 대응이 불가능한 결함들**이 드러났다.

1. **한국어 인용을 전혀 인식하지 못함** — `extract_citations` 가 `[]` 반환.
   DOI/URL/영문 저자-연도만 지원했고, 국내 표기 `(출처: 기관, 연도, 과제번호 NCT...)` 는 미지원.
   → 과제번호(NCT/NRF/NTIS)·출처 블록·한국어 저자인용(`김철수 외 (2023)`) 패턴 추가.
2. **한국어 수치 단위 미인식** — `명·건·회` 가 단위 목록에 없어 **등록례수 변조를 못 잡았다**
   (ALCOA+ `Accurate` 검증 실패). 천단위 콤마(`2,927명`)도 미지원.
   → 한국어 단위 + 콤마 표기 추가.
3. **문단 끝 인용이 앞 문장을 귀속하지 못함** — 한국어 R&D 문체는 여러 문장 뒤에 출처를
   한 번 붙인다. 기존 로직은 인용이 붙은 문장만 커버로 계산해 `source_exist=0.25`.
   → 직전 인용 이후 문장들을 현재 인용이 흡수하도록 수정(영어에도 적용되는 의미 개선).
4. **인용 조각이 주장으로 잘못 전달됨** — 문장 분리 후 `"(출처: ...)"` 자체가 NLI 입력이 되어
   `source_match=0.0`. → 인용 앞 본문을 주장으로 사용하도록 수정.

## 결과

```
python -m compliance_gateway.data.korean.build_kr   # 데이터 생성
python -m compliance_gateway.eval.korean --sweep    # 평가
```

국내 연구과제 22건 → 평가 132건(compliant 22 / 위반 110), DPO 110쌍.
ALCOA+ 4속성 전부 커버(Attributable 44 / Accurate 22 / Contemporaneous 22 / Original 22).

| θ | Precision | Recall | F1 | PASS |
|---|---|---|---|---|
| 0.86 | 100% | 99.1% | 99.5% | 100% |
| **0.94** | **100%** | **100%** | **100%** | **100%** |
| 0.98 | 83.3% | 100% | 90.9% | 0% (사용불가) |

### ⚠️ 이 100% 를 KPI 근거로 쓰지 말 것

규칙 기반 변조 합성셋이다. **우리가 만든 오류를 우리가 찾는** 구조라 낙관적이다.
bioRxiv 합성셋(F1 98.2%)과 같은 성격이며, 외부 실데이터(SciFact F1 24.0%)와
**직접 비교할 수 없다.**

| 평가셋 | 성격 | 용도 |
|---|---|---|
| 합성 KR (본 데이터셋) | 템플릿+규칙변조 | 한국어 처리 회귀 테스트 |
| 합성 EN (bioRxiv) | 실논문+규칙변조 | 서지 검증 회귀 테스트 |
| 외부 EN (SciFact) | 전문가 주석 실데이터 | **KPI 근거** |
| **외부 KR** | **미확보** | ScienceON/KCI 필요 |

## 부수 발견: 언어별 운영점이 다르다

영어 외부셋 최적 θ=0.70, 한국어 합성셋 최적 θ=0.94.
한국어 템플릿은 근거-주장 어휘 중복이 커 VCR 이 전반적으로 높다.
→ 단일 임계값으로 다국어를 처리할 수 없다. 사업계획서의
**VCR v2 도메인별 가중치 자동 최적화**가 필요한 실증 근거.
