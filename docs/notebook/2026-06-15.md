## 2. 수행

### 2.1 Compliance Gateway 7단계 파이프라인

생성 이후가 아니라 생성 전·중·후 각 지점에 제약을 건다.

```
질의 → Pre-Gen 제약주입 → 생성 → 출처 바인딩 → NLI 게이팅 → ALCOA+ 점검 → 블록체인 감사추적
                ↑                                    │
                └──────────── 미달 시 재생성 ──────────┘
```

### 2.2 VCR(Verifiable Compliance Reward) 정의 — 본 과제 핵심 IP

```
VCR(y|x) = w1·SourceExist(y) + w2·SourceMatch(y) + w3·ALCOA_Score(y) + w4·(1 − Halluc(y))
```

- 가중치 합 = 1, 출력 범위 `[0,1]`
- DPO 기준선 0.60, 목표 0.85+
- 환각 3유형 정의: **A**(가짜 DOI + 실존 저자), **B**(정교한 가짜 논문 제목), **C**(수치 변조, 예: 37°C → 25°C)

### 2.3 기타

- `SourceMatch`를 토큰 중첩 휴리스틱에서 **NLI entailment 기반**으로 교체.
- bioRxiv 실논문 기반 합성 파이프라인 구축 — 자체 데이터 부재 상태의 부트스트랩 수단.
