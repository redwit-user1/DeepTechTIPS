## 4. 정정 사항

### 정정 11 — 정규식 빈 대안

패턴 문자열 끝에 `|`가 남아 **빈 대안**이 되면서 모든 위치에 매치, "인프라 코드 100%"라는 불가능한 결과가 산출됐다.

이후 모든 신규 패턴에 다음을 걸어 재발을 차단한다.

```python
assert not PATTERN.search(""), "빈 대안 — 정규식 끝의 | 를 확인하라"
```

### 정정 12 — 커밋 해시 오탐

`[0-9a-f]{7,40}`가 순수 숫자열(`1234567`)도 해시로 인정했다. a–f를 최소 1자 요구하도록 수정.

> 80.4% → **76.5%**
