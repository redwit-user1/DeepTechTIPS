## 1. 문제 정의

### 1.1 현상

- 연구 현장의 AI 도입이 **기록 신뢰성 문제**에 막혀 있다.
- 범용 LLM은 그럴듯한 출처를 만들어낸다. R&D 기록은 **법적 증빙**이므로 이 실패가 치명적이다.
- 규제 산업(제약·바이오)에서는 기록 하나의 오류가 임상 데이터 전체의 신뢰성을 훼손한다.

### 1.2 기존 접근의 구조적 한계

| 접근 | 검증 시점 | 한계 |
|---|---|---|
| 범용 프레임워크 (LangChain 등) | **사후** | 이미 생성된 것을 검사한다. 생성 자체를 막지 못한다 |
| RAG | 검색 시점 | 검색 결과와 무관한 문장을 생성해도 걸러지지 않는다 |
| 프롬프트 제약 | 생성 전 | 모델이 지시를 무시하면 방법이 없다 |

→ **파라미터 수준에서 "출처 없는 생성"을 억제하지 않으면 구조적으로 해결되지 않는다.**

### 1.3 환각 유형 분류

단순 사실 오류가 아니라 **복합 기만형** 환각을 대상으로 한다. 셋 다 표면적으로는 정상적인 인용 형식을 갖춘다.

| 유형 | 정의 | 예시 |
|---|---|---|
| **A** | 가짜 DOI + 실존 저자 | DOI는 유효하나 해당 논문에 그 저자가 없음 |
| **B** | 정교한 가짜 논문 제목 | 전문용어 조합으로 실재할 법한 제목 생성 |
| **C** | **수치 변조** | 37°C → 25°C. 인용은 유지한 채 값만 바뀜 |

- 유형 C가 가장 탐지하기 어렵고 R&D 맥락에서 가장 위험하다. 조건·측정값이 곧 재현성이기 때문이다.

## 2. 규제 프레임 분석

### 2.1 대상 규정

| 규정 | 관할 | 본 과제 관련성 |
|---|---|---|
| **ALCOA+** | 데이터 무결성 원칙 | 9속성. VCR의 한 축으로 직접 편입 |
| **GLP** | 비임상 시험 | 초기 도메인(제약·바이오)의 기준 |
| **FDA 21 CFR Part 11** | 전자기록·전자서명 | 감사추적(audit trail) 요구 |
| GMP | 제조 | 후속 확장 |
| EU Annex 11 | 전산화 시스템 | 후속 확장 |
| ICH E6 | GCP | 후속 확장 |

### 2.2 ALCOA+ 9속성

Attributable · Legible · Contemporaneous · Original · Accurate · Complete · Consistent · Enduring · Available

- 초기 구현은 제약·바이오 핵심 4속성으로 좁힌다: **Attributable / Accurate / Complete / Consistent**
- 나머지 5속성은 시스템 계층(저장·접근통제)에서 충족되므로 모델 검증 대상이 아니다.

### 2.3 온톨로지 계층 설계

```
L1 규정주체  GLP · FDA Part 11 · ALCOA+ · GMP · EU Annex 11 · ICH E6
L2 객체
L3 속성      ALCOA+ 9속성
L4 관계      requires / violates / supersedes
```

- 표준: W3C OWL 2, BFO 상위온톨로지, Protégé, SPARQL, HermiT·Pellet reasoner
- **판단: 풀 온톨로지는 후순위.** M1~M4 동안은 규칙기반으로 ALCOA+를 커버하고 점진 전환한다.
  - 이유: 온톨로지 구축 비용이 크고, 규칙기반으로도 초기 KPI 검증이 가능하다.

## 3. 경쟁·시장 분석

- **규정위반 탐지 정밀도** 항목의 "연구개발 전" 값이 **"없음(경쟁사 전무)"** 이다. 해당 기능을 제공하는 경쟁 제품이 확인되지 않았다.
- ELN(전자연구노트) 벤더는 기록 저장·서명은 제공하나 **생성물의 근거 검증**은 제공하지 않는다.
- → 진입 지점은 "기록 저장"이 아니라 **"생성물이 기록과 일치하는가"** 다.

## 4. 초기 도메인 선정

- **제약·바이오** (GLP / FDA 21 CFR Part 11 / ALCOA+)로 좁힌다.
- 근거:
  - 규제 강도가 가장 높아 지불 의사가 크다.
  - ALCOA+가 명문화돼 있어 평가 기준을 외부에서 가져올 수 있다.
  - 수치·조건 기록이 밀도 높아 유형 C 환각 탐지의 효과가 크다.

## 5. 판단 및 차기 과제

- 사후 검증이 아니라 **생성 경로 내재화**로 방향을 확정한다.
- 다음 달 과제: 이 방향을 **자동 생성 가능한 보상 신호**로 구체화한다.
  - 사람 라벨에 의존하면 규모를 낼 수 없다.
  - "출처 존재 여부"는 객관적이고 기계로 판정 가능하다 → 보상함수의 축으로 검토한다.
