# 개발 로드맵 (Roadmap)

원칙: **Gateway-First · Data-Driven · Demo-Early**. 문서의 4년 계획을 그대로 옮기기보다,
레버리지가 가장 큰 모듈부터 압축한다. 초기 도메인은 **제약·바이오(GLP/FDA 21 CFR Part 11/ALCOA+)** 로 좁힌다.

## 마일스톤

| 단계 | 목표 | 산출물 | 검증 기준 |
|---|---|---|---|
| **M0** (현재) | 레포 스캐폴딩 + VCR/Gateway 골격 | `compliance_gateway` 모듈, VCR v0 스코어러, 7단계 파이프라인 스텁 | 단위테스트 통과 |
| **M1** | Gateway v1 (API 모델 대상) | 출처바인딩 + 환각 게이팅 + ALCOA+ 체크 + 감사로그 | GPT/Claude 출력에 실동작, 가짜 DOI/수치변조 탐지 데모 |
| **M2** | R&D Instruction 데이터 파이프라인 | GOONO 70K → (질문,답변,출처) 트리플, DPO Preference 쌍 | 5만건 목표, 전문가 교차검증 샘플 |
| **M3** | Compliance-Aligned SLM v1 | EXAONE/Qwen + LoRA + DPO 정렬 | VCR 0.60+ 기준선, 기반모델 대비 향상 |
| **M4** | R&D 에이전트 v1 + DAG | 탐색·기획 에이전트 + LangGraph + Gateway 경유 | 선행연구→갭→제안서 단일 워크플로우 |
| **M5** | In-process 게이팅 + Flywheel | 자체 LoRA 로짓 개입, 분기별 재학습(→RLVR) | VCR 자기진화 루프 |

## 성능 목표 (사업계획서 기준)

| 지표 | 연구개발 전 | 목표 |
|---|---|---|
| R&D 보고서 자동생성 정확도 | 72% | 85 → 88%+ |
| 도메인 질의 정확도 | KISTI 2.5 | 2배+ |
| AI 생성 콘텐츠 출처 정확률 | 없음 | 90%+ |
| 에이전트 워크플로우 자동화율 | 없음 | 85%+ |
| 양자화 후 성능 보존율 (FP16 대비) | 없음 | 80%+ |
| 규정위반 탐지 정밀도 (GLP/FDA Part 11/ALCOA+) | 없음(경쟁사 전무) | 90%+ |
| 규정 온톨로지 커버리지 | 없음 | 90%+ |
| 접근통제 정확도 (RBAC/ABAC) | 없음 | 99%+ |

## 스코프 방어 (의도적 후순위)

코어 3축이 VCR 0.7+ 를 찍기 전까지 아래는 착수하지 않는다.

- 멀티모달(수식·차트·현미경 이미지)
- RLVR 완전 전환
- 일본 PMDA / 싱가포르 A*STAR 모듈
- 풀 온톨로지 자동추론 (초기엔 규칙기반)
