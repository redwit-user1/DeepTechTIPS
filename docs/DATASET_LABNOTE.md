# 연구노트 가상 데이터셋 + 기록 무결성 검사

> ⚠️ **전부 가상(SYNTHETIC) 데이터다.** 실제 연구기록이 아니며 모든 레코드에
> `synthetic: true`, 과제번호 `SYN-` 접두, 가상 연구자·기관명, 상단 배너가 박혀 있다.
> 연구노트는 **법적 증빙 기록**이므로 실제 기록으로 오인되어서는 안 된다.

## 왜 만들었나

- GOONO 의 핵심 제품이 **전자연구노트(ELN)** 이고, 사업계획서의 학습 데이터도 연구노트 70K+ 다.
- 그러나 실데이터 접근이 없다. 국가연구개발 연구노트 지침의 **실제 구조**를 참고해 가상 데이터로 검증한다.
- 지금까지 확보한 국내 실데이터(임상 프로토콜)는 텍스트가 **영어**였다.
  이 데이터셋은 **자연스러운 한국어 R&D 문체**를 다루는 첫 데이터다.

## 데이터 구성

```bash
python -m compliance_gateway.data.labnote.generate --notes 40
```

- **연구노트 120건** (정상 40 / 위반 80), 원문 약 **11만 자**
- 도메인 3종(화학·재료 / 바이오 / 공학·ICT) — 사업계획서의 3개 도메인과 일치
- 산출물: `txt/` 원문(사람이 검수 가능) + `labnote_eval.jsonl` + `labnote_dpo.jsonl`

노트 구조는 실제 연구노트 양식을 따른다:
과제번호·과제명·수행기관·실험일·연구자 서명·기록일·점검자 서명 +
1.실험제목 2.실험목적 3.재료및방법 4.실험결과 5.고찰및차기계획 (+정정이력)

## 연구노트 지침 → ALCOA+ 위반 유형

지침의 필수 요건에서 도출했다. 감사·점검에서 실제로 지적되는 항목들이다.

| 위반 유형 | ALCOA+ | 감사 지적 사유 |
|---|---|---|
| `missing_signature` | Attributable | 연구자 서명 누락 — 기록 주체 특정 불가 |
| `missing_reviewer` | Attributable | 점검자(입회자) 서명 누락 |
| `backdated` | Contemporaneous | 실험일 대비 기록일 지연 — 소급 작성 의심 |
| `overwritten` | Original | 정정 이력 없이 수치 변경 — 원본 식별 불가 |
| `missing_units` | Accurate | 수치 단위 누락 — 값 해석 불가 |
| `incomplete` | Complete | 미완결 표현(TBD/추후 기재) |
| `inconsistent` | Consistent | 고찰 수치가 결과부와 불일치 |

## 핵심 발견: VCR 로는 연구노트를 평가할 수 없다

연구노트를 기존 VCR(출처 기반 생성물 검증)로 평가하자 **모든 임계값에서 정상 노트까지
전부 차단**됐다(PASS 0%). 원인은 명확하다 — **연구노트는 인용이 없다.**
1차 기록이라 외부 출처를 인용하지 않고, 그 자체가 원본 증빙이다.

`SourceExist`·`SourceMatch` 가 VCR 의 55% 를 차지하는데 구조적으로 0 에 가깝다.

→ **역할 분담이 필요하다.**

| | 검증 대상 | 질문 | 모듈 |
|---|---|---|---|
| **VCR** | AI 생성물 | 출처에 근거하는가 | `vcr/` |
| **RecordIntegrity** | 1차 기록(연구노트) | 기록 자체가 무결한가 | `integrity/` |

## 기록 무결성 검사 (`integrity/`)

텍스트 기반으로 동작한다 — 운영에서는 스캔·OCR 된 노트도 대상이 되기 때문이다.
각 검사는 점수와 함께 **감사 대응용 지적 문장**을 생성한다.

```bash
python -m compliance_gateway.eval.labnote --compare-vcr
```

| 지표 | 기록 무결성 검사 | (대조) VCR |
|---|---|---|
| AUC | **1.000** | 0.607 |
| 위반탐지 F1 | **100%** | — |
| 준수노트 PASS | **100%** | 0% |

280건 검사(노트 40 × 위반 7종)에서 **미탐 0 · 오탐 0**.

## 개발 중 잡은 오탐 — 실제 R&D 문서의 정상 패턴들

검사기를 만들면서 **정상 문서를 위반으로 오판하는 패턴**을 여럿 발견했다.
운영 환경에서 그대로 문제가 될 것들이라 기록해 둔다.

1. **무차원 지표** — `F1은 0.912`, `AUC 0.87` 등은 단위가 없는 게 정상인데
   "단위 누락"으로 오판했다. → 무차원 지표 목록으로 예외 처리.
2. **파생값** — 고찰의 `지연시간을 59% 단축`은 48.3→19.6 에서 **계산된 값**이라
   결과부에 없는 게 정상인데 "모순"으로 오판했다. → 파생·비교 표현 제외.
3. **향후 계획** — `차기 실험에서 17.5% 조건을 검토`처럼 계획 문장에는
   새 수치가 나오는 게 정상. → 계획 표현 제외.
4. **정규식이 개행을 넘어감** — `2024-04-28` 다음 줄이 `점검자:` 로 시작하면
   `28` + `점` 을 "28점"으로 매칭했다. `\s*` → `[ \t]*` 로 수정.
   **같은 버그가 `vcr/alcoa.py`, `vcr/hallucination.py` 에도 있어 함께 고쳤다.**
5. **값 소실 vs 값 교체** — 단위를 지우거나 문장을 자르면 수치가 사라지는데,
   이를 "변조"로 보면 한 위반이 여러 속성을 오염시킨다.
   → **양방향 차이(교체)** 일 때만 Original 위반으로 판정.
6. **구획 범위** — 결과부 수치를 바꿔도 같은 값이 방법부에 남아 있으면
   문서 전체 기준으로는 "사라진 값 없음"이 된다. → **결과부 단위로 비교**.

## 한계 (정직한 기술)

- **규칙으로 만든 위반을 규칙으로 찾는다** → 낙관 편향이 있다.
  AUC 1.000 은 KPI 근거가 될 수 없다. 회귀 테스트와 한국어 문체 처리 검증용이다.
- 실제 연구노트는 훨씬 다양하다(수기·표·그림·약어·오탈자·부분 스캔).
  GOONO 실데이터 확보 시 재측정이 필요하다.
- 텍스트만 다룬다. 실제 지침의 **여백 사선 처리·페이지 연속성·접착물 경계 서명**은
  레이아웃 정보가 필요해 현재 범위 밖이다.
